# Bridge API Reference

Base URL: `http://localhost:9092/api`

Auth header:

```http
Authorization: Bearer <jwt>
```

## Auth

### `POST /auth/login`

Logs in any supported role and returns a JWT.

### `POST /auth/register-user`

Registers a student or working professional account. Admin approval is still required before applying.

### `POST /auth/register-company`

Registers a company account. Admin approval is required before job posting.

### `POST /auth/forgot-password`

Sends a password reset OTP if the email exists.

Example body:

```json
{
  "email": "student@example.com"
}
```

### `POST /auth/reset-password`

Resets a password using the OTP generated by the forgot-password flow.

Example body:

```json
{
  "email": "student@example.com",
  "otp": "123456",
  "newPassword": "NewPassword@123"
}
```

## File Uploads

### `POST /files/upload`

Uploads a JPG, PNG, or PDF to Cloudinary and returns a permanent URL.

Response:

```json
{
  "url": "https://res.cloudinary.com/..."
}
```

## Public Endpoints

### `GET /public/stats`

Returns landing-page counters.

### `GET /jobs/search`

Searches public jobs.

Query params:

- `location`
- `type`

### `GET /jobs/{id}`

Returns public job details.

## User Endpoints

Role required: `USER`

### `GET /user/profile`
### `PUT /user/profile`
### `GET /user/applications`
### `POST /user/apply/{jobId}`

Applying now persists AILS score data at submission time when scoring succeeds.

### `GET /user/application/{applicationId}/interview`

Returns the latest scheduled interview for the authenticated user’s application.

### `GET /user/notifications`
### `GET /user/notifications/unread-count`
### `PUT /user/notifications/read?notificationId={id}`

Shared notification endpoints used by users, companies, and officers.

## Placement Officer Endpoints

Role required: `PLACEMENT_OFFICER`

### `GET /officer/profile`
### `PUT /officer/profile`
### `POST /officer/change-password`
### `GET /officer/jobs`
### `GET /officer/applications/{jobId}`
### `GET /officer/application/{id}`
### `PUT /officer/application/status?applicationId={id}&status={STATUS}`
### `PUT /officer/application/{id}/remark`

### `GET /applications/{id}/score`

Returns the stored AILS breakdown for a specific application.

Allowed roles:

- `USER`
- `PLACEMENT_OFFICER`
- `SUPER_ADMIN`

### `POST /officer/application/{applicationId}/schedule-interview`

Schedules an interview for an accessible application.

Example body:

```json
{
  "scheduledAt": "2026-04-10T10:30",
  "mode": "ONLINE",
  "meetingLink": "https://meet.google.com/example",
  "venue": "",
  "additionalNotes": "Join 10 minutes early"
}
```

### `GET /officer/application/{applicationId}/interview-slots`

Returns interview slots for an accessible application.

## Admin Endpoints

Role required: `SUPER_ADMIN`

The admin controller currently supports platform management, approval, blocking, deletion, analytics, activity, profile, and kanban endpoints exposed under `/admin/...`.

Note: `/admin/export/pdf` and `/admin/export/excel` are not implemented yet.
